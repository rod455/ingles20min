## Por que este cluster
Os dados de `site_events` mostram que as páginas de **maior intenção de conversão** (que geram clique no grupo grátis) são as da família **"como aprender inglês [rápido/grátis]"** — não as de vocabulário (números, cores), que trazem tráfego mas quase não convertem. Este cluster ataca justamente os termos bottom-funnel que puxam o leitor para o grupo grátis no WhatsApp.
